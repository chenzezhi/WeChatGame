# 怪物表：只放基础属性，波次机制会在此基础上加成
#
# name   - 怪物名
# kind   - 种类：normal 普通 / elite 精英 / boss 首领
# hp     - 基础血量（会按波次放大）
# speed  - 移动速度，单位 px/秒
# damage - 每次攻击篝火扣掉多少耐久
# atkCd  - 攻击间隔，单位毫秒（走到篝火旁边就按这个节奏打）
# coins  - 打死它能拿多少银币
