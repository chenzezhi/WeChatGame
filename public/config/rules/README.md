# 协议规则（rules）

这里集中管理项目里的「默认约定 / 协议」，按类别拆成不同文件。
以后加新规则，照这个分类新建一个文件即可。

## 现有规则

| 文件 | 管的规则 |
|------|----------|
| `atlas.js` | 素材 / 图集数据管理：合图图片 + 合图数据（json）的默认约定 |
| `engines.js` | 渲染引擎分工：精灵图动画引擎（atlas.js）vs 静态图集引擎（cocos-atlas.js） |

## 加新规则的约定

- 一个文件只讲一类规则，文件名 = 规则主题（如 `atlas` / `audio` / `storage`）。
- 规则写成 JS 模块（代码能直接 `require`），同时用顶部注释把协议写清楚。
- 想改默认值，改对应规则文件即可，不用动具体实现。
