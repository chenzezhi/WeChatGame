# 地板模块使用说明

改参数只动一个文件：**`features/floor/config/floor-config.js`**

---

## 一、菱形贴图为什么有缺口 / 被覆盖

两个独立原因，都要处理：

### 原因 1：按正方形平铺（几何问题）

菱形只占方框中间，四个角是空的。按 `grid` 平铺 → 透明角对透明角 → 缺口。

```js
layout: 'staggered',   // 每行半格错开，菱形咬合
```

### 原因 2：JPEG 没有透明通道（这就是「被覆盖」的真凶）

`floor-tileset.jpg` 是 **JPEG**，不支持 alpha。原来透明的四个角存成 jpg 后变成**实心色块**。
交错排布时，下一行的实心角正好压在上一行的菱形上 → 菱形被盖掉。

```js
maskDiamond: true,     // 启动时一次性把每块裁成菱形
```

> 换成带透明的 **PNG** 之后可以关掉这个开关。

## 二、三种布局

| `layout` | 公式 | 适合 |
| --- | --- | --- |
| `'grid'` | `x=col×W, y=row×H` | 方块地砖 |
| `'staggered'` | `x=col×W+(row%2)×W×sx, y=row×H×sy` | ✅ 菱形贴图 |
| `'iso'` | `x=(col−row)×W/2, y=(col+row)×H/2` | 45° 斜向地图 |

### 交错比例可调

```js
stagger: { x: 0.5, y: 0.5 }
```

| 现象 | 怎么调 |
| --- | --- |
| 菱形上下顶在一起 | `y` 调大（0.55、0.6…） |
| 菱形之间有纵向空隙 | `y` 调小（0.45、0.4…） |
| 左右错位过多/过少 | `x` 调小/调大（一般保持 0.5） |

> `stagger.y` 的物理含义：相邻两行**纵向中心间距 = H × y**。
> 标准菱形（顶点贴方框中点）正好是 `0.5`。
> 如果菱形在方框里**偏扁**（比如 56 宽只有 40 高），把 y 调成 `40/56 ≈ 0.36`。

运行时也能调：
```js
floor.setStagger(0.5, 0.4);
```

## 三、渲染策略

| | 状态 |
| --- | --- |
| 大图 | 内存里 1 份（jpg 会额外生成 1 份菱形遮罩图，只做一次） |
| 每块位置 | 不存，每次现算 |
| 预切小图 | 没有 |
| 地图 map | 存索引数字 |

绘制走 `ctx.drawImage(image, sx, sy, sw, sh, dx, dy, dw, dh)`。
逐格做屏幕裁剪，只画可见的。

## 四、缩放规则

| 条件 | scale | 结果 |
| --- | --- | --- |
| `tileDisplaySize > 0` | `tileDisplaySize / tileWidth` | 你说了算 |
| 有地图文件 或 有 `grid` 格子数 | **1** | 保持原始大小，超出就滚动 |
| 什么都没指定 | `屏宽 / (auto列数 × tileWidth)` | 自适应铺满 |

## 五、地图文件

`assets/maps/level-1.txt`：

```
17 20 17 20
2 6 7 2
. 1 1 .
```

- 数字 = 大图扁平索引（0 = 左上角第一块）
- 分隔符：空格 / Tab / 逗号
- 空格子：`.` 或 `-1`
- `#` 开头整行注释

```js
mapFile: 'assets/maps/level-1.txt',
```

## 六、调参顺序（菱形）

1. 先 `pattern: 'single'`、`tilePool: [{ row: 0, col: 0 }]`，只看**一块**
   - 确认切的这一块是**干净完整的菱形**，周围没有别的碎片
2. 开 `maskDiamond: true`，看四角是否被裁掉（会打印 `已生成菱形遮罩`）
3. 开 `layout: 'staggered'`，看菱形是否咬合
4. 还有缝/重叠 → 微调 `stagger.y`（0.36 ~ 0.6 之间试）
5. 最后把 `pattern` 改回 `'random'` 或挂上地图文件

## 七、切图参数在哪改

**`assets/atlas/floor-tileset.js`**

```js
tileWidth: 56,    // 一块的宽
tileHeight: 56,   // 一块的高
margin: 18,       // 大图最外圈留白
spacing: 20,      // 块与块之间的间隔
```

启动后看 Console：

```
[floor] 贴图就绪：512x512，切出 4x4 = 16 块，布局 staggered(0.5,0.5)，已做菱形遮罩，地图 …（8x6）
```
